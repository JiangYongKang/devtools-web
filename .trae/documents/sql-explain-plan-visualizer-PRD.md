## 1. 产品概述
SQL EXPLAIN 计划可视化工具，支持 MySQL、PostgreSQL、SQLite 三种主流数据库的执行计划解析与可视化展示，帮助开发者快速理解查询性能瓶颈。

## 2. 核心功能

### 2.1 功能模块
1. **计划解析器**：自动识别方言，解析 EXPLAIN 文本为算子节点树
2. **树形可视化**：缩进/树形视图展示算子层级关系
3. **高亮警示**：全表扫描节点高亮标记（Seq Scan/ALL/SCAN TABLE）
4. **成本摘要**：总成本、最大成本节点、预估行数统计卡
5. **交互功能**：点击节点展开详情 JSON、搜索过滤、多语句 Tab 切换
6. **示例填充**：内置三方言 EXPLAIN 样例一键填充
7. **错误处理**：无法识别格式时给出期望样例链接说明

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 主页面 | 输入区 | 多行文本框粘贴 EXPLAIN 文本，方言自动识别显示 |
| 主页面 | 示例按钮区 | MySQL/PostgreSQL/SQLite 三方言样例一键填充 |
| 主页面 | 成本摘要卡 | 显示总成本、最大成本节点、预估总行数 |
| 主页面 | 算子树视图 | 树形/缩进展示，全表扫描节点高亮 |
| 主页面 | 搜索过滤栏 | 按 table 名或算子 type 过滤节点 |
| 主页面 | 语句 Tab 栏 | 多语句结果切换 |
| 主页面 | 节点详情面板 | 点击节点显示完整 JSON 详情 |

## 3. 核心流程

用户粘贴 EXPLAIN 文本 → 自动识别方言 → 解析为算子树 → 计算成本摘要 → 渲染树形视图（全表扫描高亮）→ 用户点击节点查看详情 → 可搜索过滤或切换多语句 Tab

```mermaid
    C --> D["计算成本摘要"]
    D --> E["渲染树形视图"]
    E --> F["全表扫描节点高亮"]
    F --> G["用户交互（点击/搜索/切换 Tab）"]
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝 (#1565c0) 表示数据查询，橙红 (#e65100) 标记全表扫描警告
- 字体：Consolas 等宽字体展示代码和执行计划
- 布局：三栏布局（输入区、算子树、详情面板）
- 卡片：成本摘要卡使用浅灰背景，带微妙阴影

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 主页面 | 输入区 | 文本框、方言标签、示例按钮组、解析按钮 |
| 主页面 | 成本摘要卡 | 三个统计卡片并排，显示数值和标签 |
| 主页面 | 算子树视图 | 缩进树形，可展开/折叠，全表扫描橙色边框高亮 |
| 主页面 | 搜索过滤 | 搜索输入框、类型筛选下拉 |
| 主页面 | 详情面板 | JSON 格式化展示，复制按钮 |

### 4.3 响应式
- 桌面端：三栏布局
- 平板端：两栏布局（输入+树，详情在下方）
- 移动端：单栏堆叠，Tab 切换视图

## 5. 验收标准
- 三方言 EXPLAIN 解析正确，算子树结构完整
- 全表扫描节点正确高亮显示
- 成本摘要卡数值准确
- 点击节点展开详情 JSON 功能正常
- 搜索过滤功能按 table 名和算子 type 工作
- 多语句结果 Tab 切换正常
- 内置示例一键填充可用
- 单测覆盖 parse、算子树构建、全表扫描判定、cost 聚合
