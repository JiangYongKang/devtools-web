# DOC_004 - URL 编码与解码

## 联调环境

- 前端：`http://localhost:5173/tools/004`
- 后端 API 基址：由 `VITE_API_BASE` 环境变量配置
- 后端接口前缀：`/api/url`

## 后端接口契约

### 1. 单条编码

**POST** `/api/url/encode`

请求体：
```json
{
  "text": "hello world",
  "charset": "UTF-8",
  "style": "URI_COMPONENT"
}
```

响应包络（成功）：
```json
{
  "success": true,
  "data": {
    "result": "hello%20world",
    "charset": "UTF-8",
    "action": "ENCODE",
    "style": "URI_COMPONENT"
  }
}
```

响应包络（失败）：
```json
{
  "success": false,
  "errorCode": "INVALID_CHARSET",
  "errorMessage": "无效的字符集名称"
}
```

### 2. 单条解码

**POST** `/api/url/decode`

请求体：
```json
{
  "text": "hello%20world",
  "charset": "UTF-8",
  "style": "URI_COMPONENT"
}
```

响应包络（成功）：
```json
{
  "success": true,
  "data": {
    "result": "hello world",
    "charset": "UTF-8",
    "action": "DECODE",
    "style": "URI_COMPONENT"
  }
}
```

### 3. 批量处理

**POST** `/api/url/batch`

请求体（继续处理模式）：
```json
[
  {
    "text": "hello world",
    "action": "ENCODE",
    "charset": "UTF-8",
    "style": "URI_COMPONENT"
  },
  {
    "text": "hello%20world",
    "action": "DECODE",
    "charset": "UTF-8",
    "style": "URI_COMPONENT"
  }
]
```

请求体（快速失败模式）：
```json
[
  {
    "text": "hello world",
    "action": "ENCODE",
    "charset": "UTF-8",
    "style": "URI_COMPONENT",

  },
  {
    "text": "test%",
    "action": "DECODE"
  }

```

响应包络：

    "total": 2,

## 错误码说明

| 错误码 | 说明 | 触发场景 |
|--------|------|----------|
| `NULL_INPUT` | 输入不能为空 | `text` 字段为 `null` 或未提供 |
| `INVALID_CHARSET` | 无效的字符集名称 | 字符集名称不被 Java 支持 |
| `INVALID_ACTION` | 无效的操作类型 | 批量操作中 `action` 不是 `ENCODE`/`DECODE` |
| `ENCODE_FAILED` | 编码失败 | 编码过程中发生错误 |
| `DECODE_FAILED` | 解码失败 | 解码过程中发生错误 |
| `INVALID_PERCENT_SEQUENCE` | 无效的百分号序列 | 不完整的 `%` 或非十六进制字符（如 `%G0`、`test%`） |
| `INVALID_UTF8_SEQUENCE` | 无效的 UTF-8 字节序列 | 解码得到的字节不是合法的 UTF-8 序列 |
| `HTTP_ERROR` | 网络请求失败 | 网络不可达、CORS 错误等 |

## 验证步骤

### 1. 基础编码验证

1. 打开页面 `http://localhost:5173/tools/004`
2. 在输入框输入：`hello world`
3. 选择字符集：`UTF-8`
4. 选择风格：`URI_COMPONENT`
5. 点击「编码 (Encode)」
6. **预期结果**：输出 `hello%20world`

### 2. FORM 风格编码验证

1. 选择风格：`FORM`
2. 点击「编码 (Encode)」
3. **预期结果**：输出 `hello+world`

### 3. 基础解码验证

1. 在输入框输入：`hello%20world`

### 10. 空字符串验证

1. 清空输入框

3. **预期结果**：输出空字符串（合法，不报错）

### 11. 批量处理 - 继续处理模式

1. 展开「批量处理」
2. 保持默认两条：
   - #1: `hello world` + ENCODE + UTF-8 + URI_COMPONENT
   - #2: `hello%20world` + DECODE + UTF-8 + URI_COMPONENT
3. 确保「快速失败」未勾选
4. 点击「执行批量操作」
5. **预期结果**：
   - 总计 2 条
   - 成功 2 条
   - #1 输出 `hello%20world`
   - #2 输出 `hello world`

### 12. 批量处理 - 混合成功失败（继续处理）

1. 展开「批量处理」
2. 添加第 3 条：
   - #3: `test%` + DECODE
3. 确保「快速失败」未勾选
4. 点击「执行批量操作」
5. **预期结果**：
   - #1 成功
   - #2 成功
   - #3 失败（显示 `[INVALID_PERCENT_SEQUENCE]`）
   - 所有结果按顺序展示，不掩盖已成功项

### 13. 批量处理 - 快速失败模式

1. 展开「批量处理」
2. 配置条目：
   - #1: `hello world` + ENCODE（勾选「快速失败」）

2. **预期结果**：右上角显示「复制成功」提示，剪贴板内容正确

## CURL 参考示例

### 单条编码
```bash
curl -X POST http://localhost:8080/api/url/encode \
  -H "Content-Type: application/json" \
  -d '{"text":"hello world","charset":"UTF-8","style":"URI_COMPONENT"}'
```

### 单条解码
```bash
curl -X POST http://localhost:8080/api/url/decode \
  -H "Content-Type: application/json" \
  -d '{"text":"hello%20world","charset":"UTF-8","style":"URI_COMPONENT"}'
```

### 批量处理
```bash
curl -X POST http://localhost:8080/api/url/batch \
  -H "Content-Type: application/json" \
  -d '[
    {"text":"hello world","action":"ENCODE","charset":"UTF-8","style":"URI_COMPONENT"},
    {"text":"hello%20world","action":"DECODE"}
  ]'
```

## 注意事项

1. **编码风格差异**：
   - `URI_COMPONENT`：空格 → `%20`，星号按 RFC 3986 规则编码
   - `FORM`：空格 → `+`，适用于 `application/x-www-form-urlencoded`

2. **解码特性**：
   - 百分号序列大小写不敏感（`%2f` 与 `%2F` 等价）
   - `FORM` 风格下 `+` 被解码为空格

3. **XSS 防护**：
   - 所有用户输入、错误信息、结果均经 `escapeHtml` 转义后展示
   - 不直接将用户输入作为 HTML 渲染

4. **请求取消**：
   - 使用 `AbortController` 支持请求取消
   - 重复触发同一操作时自动取消上一个请求

5. **空字符串**：
   - 空字符串 `""` 是合法输入
   - 编码/解码后仍为空串
