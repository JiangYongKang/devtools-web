# DOC_006 - 哈希摘要

## 概述

本工具提供 **纯前端** 的哈希摘要计算功能，支持 MD5、SHA-1、SHA-256、SHA-384、SHA-512 等常用算法。所有计算均在浏览器本地执行，**不向任何后端服务器发送数据**，可在离线或无后端环境下使用。

## 访问地址

- 前端页面：`http://localhost:5173/tools/006`

| 依赖 | 用途 | 说明 |
|------|------|------|

## 功能说明

### 支持的算法

| 算法 | 输出长度 | 实现来源 | 安全等级 | 推荐用途 |
|------|----------|----------|----------|----------|
| MD5 | 128 位 (32 hex) | 自定义 JS | **已废弃** | 仅兼容性用途，不可用于安全场景 |
| SHA-1 | 160 位 (40 hex) | Web Crypto | **已废弃** | 仅兼容性用途，不可用于安全场景 |
| SHA-256 | 256 位 (64 hex) | Web Crypto | **推荐** | 大多数安全场景 |
| SHA-384 | 384 位 (96 hex) | Web Crypto | **推荐** | 高安全性要求 |
| SHA-512 | 512 位 (128 hex) | Web Crypto | **推荐** | 最高安全性 |

### 输入方式

| 方式 | 说明 | 入口 |
|------|------|------|
| 文本输入 | UTF-8 编码文本 | 文本框输入 |
| 文件输入 | 任意类型文件 | 文件选择 / 拖拽 / 粘贴 |
| 粘贴文件 | 从剪贴板粘贴图片等文件 | 直接 `Ctrl+V` 到页面 |

### 输出格式

- **十六进制（Hex）**：小写字母，业界标准表示方式
- 例如：`hello world` 的 SHA-256 为 `b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2efcde9`

### 计算流程

```
文本/文件 → ArrayBuffer → 算法计算 → ArrayBuffer → 十六进制字符串
                                                      ↓
                                                   复制 / 下载
```

## 关键实现细节

### 1. Web Crypto API 边界处理

**说明**：Web Crypto API 是浏览器提供的加密 API，性能优秀但有使用限制。

**关键代码**（DigestTool.jsx:200-219）：

```javascript
async function computeDigest(buffer, algorithm) {
  const algo = ALGORITHMS.find(a => a.id === algorithm)
  if (!algo) {
    throw new Error(`不支持的算法: ${algorithm}`)
  }

  if (algo.source === 'webcrypto') {
    if (!crypto?.subtle) {
      throw new Error('当前环境不支持 Web Crypto API，请使用现代浏览器')
    }
    const result = await crypto.subtle.digest(algorithm, buffer)
    return arrayBufferToHex(result)
  }

  if (algo.id === 'MD5') {
    return MD5(buffer)
  }

  throw new Error(`算法 ${algorithm} 实现不可用`)
}
```

**注意事项**：
- `crypto.subtle` 仅在 **HTTPS** 或 **localhost** 环境下可用（浏览器安全策略）
- 非安全环境下（如 file:// 协议或 HTTP）会降级报错

### 2. MD5 自定义实现

**说明**：Web Crypto API 不包含 MD5 算法（因已被废弃），需纯 JavaScript 实现。

**关键代码**（DigestTool.jsx:49-198）：

```javascript
const MD5 = (function () {
  // 轮函数 F, G, H, I
  function F(x, y, z) { return (x & y) | ((~x) & z) }
  function G(x, y, z) { return (x & z) | (y & (~z)) }
  function H(x, y, z) { return x ^ y ^ z }
  function I(x, y, z) { return y ^ (x | (~z)) }

  // 循环左移
  function rotateLeft(x, n) {
    return (x << n) | (x >>> (32 - n))
  }

  // 64 轮变换（FF, GG, HH, II 各 16 轮）
  // ...

  return function (buffer) {
    // 填充、分块、迭代计算
    // ...
    return wordToHex(a) + wordToHex(b) + wordToHex(c) + wordToHex(d)
  }
})()
```

**注意事项**：
- 纯 JS 实现性能低于 Web Crypto 的原生实现
- 大文件计算可能较慢，建议限制在 10MB 以内

### 3. 多算法批量计算

**说明**：用户可同时选择多个算法，一次性计算所有结果。

**关键代码**（DigestTool.jsx:359-374）：

```javascript
const newResults = {}
for (const algoId of selectedAlgorithms) {
  try {
    const hex = await computeDigest(buffer, algoId)
    newResults[algoId] = { hex, error: null }
  } catch (err) {
    newResults[algoId] = { hex: null, error: err?.message || '计算失败' }
  }
}
```

**设计策略**：
- 单个算法失败不影响其他算法的计算
- 错误信息独立展示在对应算法的结果区域

## 安全说明

### 弱摘要算法警告

**MD5**：
- 2004 年王小云院士团队公布了 MD5 碰撞攻击方法
- 2008 年实现了伪造 CA 证书的实际攻击
- **不可用于**：数字签名、消息认证码（MAC）、密码哈希存储

**SHA-1**：
- 2017 年 Google 和 CWI 公布了首个 SHA-1 碰撞（SHAttered）
- 2020 年实现了选择前缀碰撞攻击
- 各大浏览器已停止信任 SHA-1 签名的证书

### 推荐实践

| 场景 | 推荐算法 |
|------|----------|
| 文件完整性校验（非安全场景） | SHA-256 |
| 密码存储 | Argon2 / bcrypt / scrypt（**非本工具用途**） |
| 数字签名 | SHA-256 + RSA / ECDSA |
| HMAC（消息认证） | HMAC-SHA256 |
| 区块链（如 Bitcoin） | SHA-256 |

## 性能与限制

### 文件大小限制

| 场景 | 建议限制 | 说明 |
|------|----------|------|
| 文本输入 | 无硬限制 | 过大文本可能导致内存占用高 |
| 文件输入 | 10 MB | 超过建议提示但不强制阻止 |
| 超大文件（> 50 MB） | 不推荐 | 可能导致页面卡顿或内存不足 |

### 性能对比（估算）

| 算法 | 实现方式 | 相对性能 |
|------|----------|----------|
| SHA-256 | Web Crypto | 100%（基准） |
| SHA-512 | Web Crypto | 约 60-80% |
| MD5 | 纯 JS | 约 10-20% |

### 已知限制

1. **Web Crypto API 环境限制**：
   - 仅在 HTTPS 或 localhost 可用
   - 非安全环境下 SHA 系列不可用

2. **MD5 性能**：
   - 纯 JS 实现较慢
   - 大文件计算可能需要较长时间

3. **浏览器内存限制**：
   - 整个文件需一次性读入内存
   - 超大文件可能导致 OOM（内存不足）

## XSS 防护

### 防护策略

1. **所有用户输入**：经 `escapeHtml()` 转义后展示
2. **所有错误信息**：经 `escapeHtml()` 转义后展示
3. **所有结果文本**：经 `escapeHtml()` 转义后展示
4. **文件名展示**：经 `escapeHtml()` 转义

### 转义实现

```javascript
function escapeHtml(text) {
  if (text == null) return ''
  const str = String(text)
  const div = document.createElement('div')
  div.textContent = str  // 利用 DOM 自动转义
  return div.innerHTML
}
```
