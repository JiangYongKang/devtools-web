# DOC_007 - 随机 UUID

## 概述

本工具提供 **纯前端** 的 UUID 生成、解析、校验与格式转换功能。支持版本 4（随机）UUID 生成，并可解析所有版本 UUID 的格式与结构。所有操作均在浏览器本地执行，**不向任何后端服务器发送数据**，可在离线或无后端环境下使用。

## 访问地址

- 前端页面：`http://localhost:5173/tools/007`

## 关键实现细节

### 1. 随机源与降级策略

**说明**：UUID 生成优先使用现代浏览器的加密级随机数生成器，降级方案用于兼容旧浏览器。

**关键代码**（uuidUtils.js:19-41）：

```javascript
function generateUUID() {
  if (typeof crypto !== 'undefined' && typeof crypto.randomUUID === 'function') {
    return crypto.randomUUID()
  }

  /**
   * 降级方案：使用 Math.random() 生成 V4 UUID
   * 说明：Math.random() 非密码学安全，仅用于不支持 crypto.randomUUID() 的旧浏览器
   */
  const hex = []
  for (let i = 0; i < 36; i++) {
    if (i === 8 || i === 13 || i === 18 || i === 23) {
      hex[i] = '-'
    } else if (i === 14) {
      hex[i] = '4'
    } else if (i === 19) {
      hex[i] = ((Math.random() * 4) | 8).toString(16)
    } else {
      hex[i] = (Math.random() * 16 | 0).toString(16)
    }
  }
  return hex.join('')
}
```

**注意事项**：
- `crypto.randomUUID()` 是 RFC 4122 版本 4 UUID，使用加密级随机数
- `crypto.randomUUID()` 在现代浏览器（Chrome 92+、Firefox 95+、Safari 15.4+）中可用
- 降级方案使用 `Math.random()`，**非密码学安全**，仅用于兼容性

### 2. 解析与标准化

**说明**：解析功能支持多种输入格式，统一标准化为小写标准格式。

**关键代码**（uuidUtils.js:64-111）：

```javascript
function normalizeUUID(input) {
  if (!input || typeof input !== 'string') return null

  let clean = input.trim()

  /** 去除 URN 前缀 */
  if (clean.startsWith('urn:uuid:')) {
    clean = clean.slice(9)
  }

  /** 去除大括号 */
  if (clean.startsWith('{') && clean.endsWith('}')) {
    clean = clean.slice(1, -1)
  }

  /** 去除连字符 */
  clean = clean.replace(/-/g, '')
  clean = clean.toLowerCase()

  /** 长度与格式校验 */
  if (clean.length !== 32) return null
  if (!/^[0-9a-f]{32}$/.test(clean)) return null

  /** 重组为标准格式 */
  return [
    clean.slice(0, 8),
    clean.slice(8, 12),
    clean.slice(12, 16),
    clean.slice(16, 20),
    clean.slice(20, 32),
  ].join('-')
}
```

**解析宽松度说明**：
- 自动处理：首尾空白、URN 前缀、大括号、连字符、大小写
- 严格校验：长度必须为 32 位十六进制字符（去除格式字符后）

### 3. 版本与变体识别

**说明**：从 UUID 中提取版本和变体信息。

**关键代码**（uuidUtils.js:115-155）：

```javascript
function parseUUID(input) {
  const normalized = normalizeUUID(input)
  if (!normalized) return null

  const parts = normalized.split('-')
  const hex = normalized.replace(/-/g, '')

  /** 版本：第 13 个字符（索引 12） */
  const versionChar = hex[12]
  const version = parseInt(versionChar, 16)

  /** 变体：第 17 个字符（索引 16） */
  const variantChar = hex[16]
  const variantNibble = parseInt(variantChar, 16)

  let variantName = 'reserved'
  if ((variantNibble & 0x80) === 0x80) {
    if ((variantNibble & 0xC0) === 0x80) {
      variantName = 'RFC 4122'
    } else if ((variantNibble & 0xE0) === 0xC0) {
      variantName = 'Microsoft'
    } else {
      variantName = 'reserved'
    }
  } else if ((variantNibble & 0xC0) === 0x00) {
    variantName = 'NCS'
  }
  // ...
}
```

**变体判断规则**（RFC 4122）：

| 变体 | 二进制模式 | 十六进制范围 | 说明 |
|------|-----------|-------------|------|
| NCS | `0xxx` | 0-7 | 向后兼容 NCS（Network Computing System） |
| RFC 4122 | `10xx` | 8-b | 当前标准，本工具生成使用 |
| Microsoft | `110x` | c-d | 向后兼容 Microsoft GUID |
| Reserved | `111x` | e-f | 保留供未来使用 |

## 安全说明

### 随机数安全等级

| 随机源 | 安全等级 | 说明 |
|--------|---------|------|
| `crypto.randomUUID()` | ✅ 密码学安全 | 符合 NIST SP 800-90A 标准 |
| `Math.random()` | ❌ 非密码学安全 | 可能被预测，不用于安全敏感场景 |

### 降级场景

当 `crypto.randomUUID()` 不可用时（极旧浏览器），工具会自动降级到 `Math.random()`。此场景下：
- 生成的 UUID 仍符合格式规范
- **但不保证不可预测性**
- 不应用于需要密码学安全的场景（如会话令牌、安全密钥等）

### 数据隐私

- 所有操作在浏览器本地执行
- 不向任何服务器发送 UUID 或输入数据
- 剪贴板操作仅在用户点击「复制」时触发

### 转义实现

```javascript
function escapeHtml(text) {
  if (text == null) return ''
  const str = String(text)
  const div = document.createElement('div')
  div.textContent = str  // 利用 DOM 自动转义
  return div.innerHTML
}
```

## 注意事项

1. **纯前端实现**：
   - 无后端依赖
   - 无网络请求
   - 数据安全，不会上传到任何服务器

2. **UUID 版本**：
   - 生成：固定为版本 4（随机）
   - 解析：支持所有版本（1-5）的格式与结构分析

3. **随机源安全**：
   - 优先使用 `crypto.randomUUID()`（密码学安全）
   - 降级到 `Math.random()`（非密码学安全，仅兼容）

4. **解析宽松度**：
   - 支持多种输入格式（标准、无分隔符、大小写、大括号、URN）
   - 不执行版本/变体语义校验（仅格式校验）
   - 例如：版本字符为 `f` 时仍可解析（格式正确但语义无效）

5. **无障碍支持**：
   - 所有按钮可聚焦
   - 使用语义化 HTML
   - 支持键盘导航

6. **响应式设计**：
   - 移动端适配
   - 小屏下单列布局
