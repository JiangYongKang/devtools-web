# DOC_009 - HTML 美化与压缩

## 概述

本工具提供 **纯前端** 的 HTML 源码美化与压缩功能，所有处理均在浏览器本地执行，**不向任何后端服务器发送数据**。

## 访问地址

- 前端页面：`http://localhost:5173/tools/009`

## 技术实现

### 核心依赖

- **无第三方库**：纯 JavaScript 实现 HTML 分词与字符串处理
- **自定义 HTML Tokenizer**：轻量级分词器，区分注释、标签、文本等 Token 类型
- **DOM 原生转义**：`div.textContent / innerHTML` 进行 XSS 安全展示

## 关键实现细节

### 1. HTML Tokenizer

**说明**：采用轻量级基于字符串的分词器，而非完整的 DOM 解析。

**支持的 Token 类型**：

| Token 类型 | 说明 |
|-----------|------|
| `COMMENT` | HTML 注释 `<!-- ... -->` |
| `DOCTYPE` | 文档类型声明 `<!DOCTYPE ...>` |
| `OPEN_TAG` | 开始标签 `<div>` |
| `SELF_CLOSING_TAG` | 自闭合标签 `<br />` |
| `CLOSE_TAG` | 结束标签 `</div>` |
| `TEXT` | 文本内容 |
| `CDATA` | CDATA 区域 `<![CDATA[...]]>` |
| `SCRIPT_CONTENT` | script 标签内的脚本内容 |
| `STYLE_CONTENT` | style 标签内的 CSS 内容 |

**关键代码**（htmlUtils.js:79-255）：

```javascript
function tokenizeHtml(html) {
  // 解析注释
  if (html.startsWith('<!--', index)) {
    parseComment()
  }
  // 解析 DOCTYPE
  else if (html.slice(index, index + 9).toLowerCase().startsWith('<!doctype')) {
    parseDoctype()
  }
  // 解析标签
  else if (html[index] === '<') {
    parseTag()
  }
  // 解析文本
  else {
    parseText()
  }
}
```

### 2. 自闭合标签与特殊内容标签

**自闭合标签列表**（htmlUtils.js:49-52）：

```javascript
const SELF_CLOSING_TAGS = new Set([
  'area', 'base', 'br', 'col', 'embed', 'hr', 'img', 'input',
  'link', 'meta', 'param', 'source', 'track', 'wbr',
])
```

**特殊内容标签列表**（htmlUtils.js:54-61）：

```javascript
const RAW_TEXT_TAGS = new Set(['script', 'style', 'textarea', 'pre'])
```

**策略说明**：
- script、style 标签内的内容作为原始文本处理，不解析为 HTML
- pre、textarea 标签内的空白在压缩时保持原样

### 3. 美化排版策略

**行内元素保持紧凑**：
- a、span、strong、em、b、i、code 等行内元素不换行
- 减少不必要的换行，保持可读性

**块级元素独立成行**：
- div、p、section、header、footer、ul、li、table 等元素独立成行
- 子元素自动缩进一层

### 4. 压缩策略

**空白压缩规则**：
- 连续空白字符合并为单个空格
- 标签间空白（`> <`）完全移除
- 文本内容中的空白仅合并，不完全移除

**注释处理**：
- 默认移除所有 HTML 注释
- 可通过选项 `removeComments: false` 保留注释

## XSS 防护与边界说明

### XSS 防护策略

1. **用户输入展示**：所有用户输入在页面上展示时均经 `escapeHtml()` 转义
2. **错误信息展示**：所有错误信息经 `escapeHtml()` 转义后展示
3. **结果展示**：处理结果在 `<pre>` 标签中展示，经 `escapeHtml()` 转义
4. **不使用 `innerHTML` 直接渲染未转义内容**

### 转义实现

```javascript
function escapeHtml(text) {
  if (text == null) return ''
  const str = String(text)
  const div = document.createElement('div')
  div.textContent = str  // 利用 DOM 自动转义
  return div.innerHTML
}
```

### 重要边界说明

**本工具不做 XSS 消毒**：
- 仅做格式转换（美化/压缩），不修改 HTML 内容语义
- 不检查或移除危险标签（如 `<script>`、`<iframe>`）
- 不验证 HTML 语法正确性
- 不做输出编码或消毒处理

**使用警告**：
- 处理后的 HTML 若用于渲染，需自行进行 XSS 消毒
- 本工具不适用于作为 XSS 防护措施

## 性能与限制

### 输入大小限制

| 场景 | 建议限制 | 说明 |
|------|----------|------|
| 普通使用 | 500 KB 以内 | 推荐最佳体验 |
| 警告阈值 | > 500 KB | 显示警告提示但允许继续 |
| 硬限制 | > 1 MB | 抛出错误拒绝处理 |

### 性能影响

- 纯 JavaScript 实现，不使用浏览器原生 HTML 解析器
- 大文件处理可能导致页面暂时卡顿
- 建议在现代浏览器中使用

### 已知限制

1. **HTML 语法容错**：
   - 对格式正确的 HTML 处理效果最好
   - 极端错误的 HTML（如 `<div <span>`）可能无法得到预期结果

2. **不支持完整 HTML5 解析**：
   - 不处理 SVG、MathML 等特殊命名空间
   - 不解析 HTML5 中的特殊规则（如 `<p>` 自动闭合）

3. **注释保留**：
   - 条件注释（`<!--[if IE]>`）在压缩时默认被移除
