### 任务目标

1. 在浏览器内计算常用摘要（如 MD5、SHA 系列），展示结果并支持复制或下载等常见操作。
2. 不调用后端 API；纯前端。

### 任务要求

1. 算法与输出格式（如十六进制）在界面上可选或可说明；错误可诊断。
2. 大输入时的体验与限制在 DOC 说明即可。

### 任务约束

1. 页面与逻辑分离：摘要计算、缓冲区与进制转换等与 UI 无关的代码须在 `src/tools/digest/` 内独立模块中实现，页面组件只做绑定与展示；不得在单一 JSX 文件中内联完整算法或通用工具函数大块。
2. 禁止后端请求；不可用 `src/services/*Api` 完成本任务。
3. 与用户说明弱摘要算法在安全场景下的不适用性（文案或说明区即可，篇幅由研发把握）。

### 实现位置

须在 `devtools-web/src/tools/digest/` 下实现本任务全部代码；外链路由与导航可按惯例置外，DOC 中注明。

### 交付产物

1. 上述目录内实现。
2. `docs/DOC_006.md`。

### 注释规范

算法选择与 Web Crypto 等能力边界处简要中文说明。

### 验收标准

1. 离线或无后端环境下可用；构建与脚本以 `package.json` 为准并完成手测关键路径。
2. DOC 与实现一致。
