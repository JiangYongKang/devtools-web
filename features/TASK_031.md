### 任务目标
- 支持将十六进制串解码为可打印文本（默认 UTF-8 字节语义，可选与 Latin-1 视图对照说明）、以及将文本编码为十六进制；支持分隔符（无空格/空格/冒号）、大小写输出、奇数字节长度与非法十六进制字符的明确报错与错位提示。
- 提供示例一键填充（ASCII、含中文 UTF-8、带分隔符样例、非法样例）、双向一键复制与清空、输入长度与输出体积的页内上限提示与截断策略说明（禁止静默损坏二进制语义）。
- 对空输入、非十六进制字符、奇数长度半字节、解码后非 UTF-8 替换或严格失败策略（须在 UI 可选并写入逻辑契约）分别给出 `errorCode` 与可读文案；大体量输入采用节流或分块处理并在页内说明。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/hex-text-converter/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/hex-text-converter/logic/`
- 测试文件夹：`devtools-web/src/tools/hex-text-converter/__tests__/`
### API 信息
- 无后端 HTTP 调用；编解码仅在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `hex-text-converter` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中双向转换、选项、示例、复制与各类错误分支均可逐条在页面上验收。
- 纯 JS 单测覆盖编码/解码主干、非法字符、奇数长度、长度守卫与错误码映射。
