### 任务目标
- 支持用户粘贴 PEM 格式证书（单段或多段证书链），在浏览器内解析并展示摘要字段（如主题、颁发者、序列号、有效期起止、公钥算法与长度、指纹类摘要等，以实际解析能力为准并在页内声明不支持私钥块或仅展示「已检测到 PRIVATE KEY 块但不解析」提示）。
- 提供示例一键填充（自签名样例或测试用 PEM 片段）、字段分区展示、一键复制各字段与原始 PEM；对畸形 PEM、非证书类 PEM、Base64 损坏给出 `errorCode` 与可读说明。
- 将证书文本当纯文本或安全结构化渲染，防 XSS；说明本工具不联网校验吊销、不做信任链验证，仅本地展示。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/pem-certificate-viewer/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/pem-certificate-viewer/logic/`
- 测试文件夹：`devtools-web/src/tools/pem-certificate-viewer/__tests__/`
### API 信息
- 无后端 HTTP 调用；解析与摘要计算在浏览器内完成（可使用本目录内允许的依赖，不得要求用户上传至服务器）。
### 任务约束
- 当前任务只允许读取和修改 `pem-certificate-viewer` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中粘贴解析、摘要展示、示例、复制、错误分支与私钥提示均可逐条验收。
- 纯 JS 单测覆盖 PEM 切块、成功摘要字段抽取主干与多条解析失败分支（以逻辑层导出函数为准）。
