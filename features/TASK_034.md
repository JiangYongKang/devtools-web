### 任务目标
- 支持按规则生成随机强口令：长度上下界、字符类（大小写、数字、符号）必选与可选组合、排除易混淆字符与同形字、排除用户自定义子串列表；支持一次生成多条并展示每条强度或熵的简要说明（定义须在页内固定并与逻辑一致）。
- 提供示例一键填充（常见规则预设）、复制全部或单条、刷新重新生成；当规则互斥或无法满足最小字符类覆盖时返回明确 `errorCode` 与建议调整文案，禁止静默生成弱于规则声明的口令。
- 使用 `crypto.getRandomValues` 或同等安全随机源；对批量条数与总输出长度设页内上界并说明；空规则或零长度等边界有独立提示。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/password-generator/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/password-generator/logic/`
- 测试文件夹：`devtools-web/src/tools/password-generator/__tests__/`
### API 信息
- 无后端 HTTP 调用；随机数与规则校验均在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `password-generator` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中规则组合、多口令生成、示例、复制、互斥规则报错均可逐条验收。
- 纯 JS 单测覆盖可满足规则的主路径、互斥规则、长度越界与字符类不可满足分支。
