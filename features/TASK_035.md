### 任务目标
- 支持按段落数或目标字数生成占位假文：段落分隔策略、是否含标题行、字数统计口径（含或不含空格等在页内固定）、可选固定种子下可复现与真随机两种模式（若同时提供须在 UI 标明语义差异）。
- 提供多组示例一键填充、复制全文与下载为 `.txt`；对段落数、单段字数、总字数乘积设页内上界，超限给出 `errorCode` 与建议，禁止静默截断后不提示。
- 大体量生成时采用分帧或节流生成并在页内说明；生成内容无外链、无脚本，仅作版面占位说明。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/lorem-ipsum-generator/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/lorem-ipsum-generator/logic/`
- 测试文件夹：`devtools-web/src/tools/lorem-ipsum-generator/__tests__/`
### API 信息
- 无后端 HTTP 调用；文本合成仅在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `lorem-ipsum-generator` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中按段/按字生成、种子语义、示例、复制下载、上限与错误提示均可逐条验收。
- 纯 JS 单测覆盖字数统计、种子可复现性（若实现）、上限守卫与非法参数分支。
