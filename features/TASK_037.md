### 任务目标
- 支持 CSV 与表格形文本（定界符可配置、可选表头行、引号与转义规则在页内固定）之间的行列互转与转置预览；支持 TSV 快捷切换、分隔符自动探测（若实现则须在页内说明探测失败回退策略）。
- 提供示例一键填充（含引号内换行、不规则列数样例）、网格预览与复制 TSV/CSV；对引号未闭合、列数不一致策略（报错或按规则填充）须在 UI 可选并与逻辑一致，且给出 `errorCode`。
- 对输入行数、列数与单元格字节上界做页内限制并提示；大体量输入使用虚拟列表或分块渲染策略之一并在页内说明。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/csv-table-transform/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/csv-table-transform/logic/`
- 测试文件夹：`devtools-web/src/tools/csv-table-transform/__tests__/`
### API 信息
- 无后端 HTTP 调用；解析与转置仅在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `csv-table-transform` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中互转、转置、分隔符与引号规则、示例、预览与错误策略均可逐条验收。
- 纯 JS 单测覆盖 RFC4180 切片内典型行、引号内换行、列不齐与转置形状守卫。
