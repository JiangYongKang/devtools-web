### 任务目标
- 支持对用户粘贴的 JSON 文本进行语法校验，并在失败时给出尽量精确的错误定位（行号、列号或字符偏移之一与页内一致）、错误片段上下文与可读说明；合法时可选提供紧凑/格式化预览切换（仅展示，不改变校验结论）。
- 提供示例一键填充（合法对象数组、常见语法错误如尾逗号/缺引号）、一键跳转错误位置、复制诊断信息；对 JSON 标准切片（是否允许注释等）在页内固定声明，禁止与 `JSON.parse` 行为 silently 不一致却不说明。
- 对空输入、超大文档与嵌套深度设页内上界并给出 `errorCode`；大体量校验使用节流或 Worker 并在页内说明；输出区防 XSS，仅安全展示文本。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/json-syntax-check/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/json-syntax-check/logic/`
- 测试文件夹：`devtools-web/src/tools/json-syntax-check/__tests__/`
### API 信息
- 无后端 HTTP 调用；校验与定位仅在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `json-syntax-check` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中合法/非法校验、定位、示例、格式化预览与体积深度守卫均可逐条验收。
- 纯 JS 单测覆盖合法解析、多种语法错误定位字段、深度与长度超限分支。
