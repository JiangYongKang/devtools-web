### 任务目标
- 支持粘贴 `.env` 风格键值文本：解析键值对、剥离可选 `export` 前缀、处理引号包裹值与行尾注释、处理反斜杠续行（规则在页内固定）；对重复键列出全部出现位置与行号并给出合并视图或告警列表。
- 提供示例一键填充（含重复键、续行、注释）、表格化展示、复制为排序键列表或 TSV；对非法行、未闭合引号、非 UTF-8 二进制粘贴等给出 `errorCode` 与修复建议。
- 对总行数与单行长度设页内上界；说明本工具不写入系统环境变量、不联网；大体量输入有节流或分块策略说明。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/env-key-parser/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/env-key-parser/logic/`
- 测试文件夹：`devtools-web/src/tools/env-key-parser/__tests__/`
### API 信息
- 无后端 HTTP 调用；解析仅在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `env-key-parser` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中解析规则、重复键报告、示例、展示与错误分支均可逐条验收。
- 纯 JS 单测覆盖续行、注释、重复键聚合、非法引号与行数守卫。
