### 任务目标
- 支持用户输入 `.gitignore` 风格通配模式（单行或多行），在浏览器内给出人类可读的含义说明（逐条解释 `*`、`?`、`[]`、`**`、前导 `/`、尾 `/`、否定 `!` 等在本工具声明的子集内）；对无法解释或超出子集的模式单独标注原因而非静默省略。
- 提供示例一键填充（目录忽略、否定规则、双星递归等）、复制解释结果与原始模式；若同时提供「与路径样例匹配预览」则匹配规则必须与解释子集一致并在页内列出假设。
- 对模式条数与单条长度设页内上界；声明与真实 Git 版本行为可能存在的差异；空输入与全注释输入有明确提示与 `errorCode`。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/gitignore-pattern-explainer/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/gitignore-pattern-explainer/logic/`
- 测试文件夹：`devtools-web/src/tools/gitignore-pattern-explainer/__tests__/`
### API 信息
- 无后端 HTTP 调用；模式解释与可选匹配预览均在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `gitignore-pattern-explainer` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中子集声明、逐条解释、示例、复制、不支持模式标注与上限均可逐条验收。
- 纯 JS 单测覆盖典型模式解释主干、否定与 `**` 组合、非法转义或超长列表分支。
