### 任务目标
- 支持在浏览器内解析与比较语义化版本字符串：核心能力含 `major.minor.patch` 与可选先行版（`alpha`/`beta`/`rc` 等词法切片须在页内固定）、可选 `+build` 元数据、前导 `v` 剥离、每段前导零规范化；提供两两比较（小于/等于/大于/兼容于 `^` `~` 等范围算子可选集）、多版本列表稳定排序、重复版本去重选项、以及「仅校验不排序」模式。
- 提供丰富 UI 与导出：多行粘贴自动分行、分隔符（换行/逗号/分号）识别开关、排序键下拉（严格 semver / 构建元数据参与与否）、升降序与并列时次级键（原始插入序或字典序）；表格展示每段的数值化视图、先行版优先级条、非法行高亮；一键复制排序结果 TSV、导出为 JSON 数组、与「diff」视图对比排序前后位置变化。
- 提供示例一键填充（含先行版链、等长不同先行级、同 patch 不同 build、非法行混排）、空行与注释行（若支持 `#` 行须在页内声明）过滤策略；对非法 semver、空段、过大数字段、超长整表设 `errorCode` 与行级诊断，禁止静默丢弃非法行却仍标全成功。
- 提供范围与集合辅助：输入 `^1.2.3` 或 `~2.0.0` 时解析约束并在表格中勾选「是否满足该范围」列（算子语义页内固定）；支持「找出列表中满足某范围的最大/最小版本」与「聚类：相同 major 分组」等派生视图（实现须落在本目录逻辑层）。
- 大体量列表（行数上界页内声明）使用节流解析或 Web Worker 分片并在页内说明；所有选项变更可「分享当前配置」同步到 URL 查询参数（与路由约定一致时可复用项目模式）；纯文本展示防 XSS。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/semver-compare-sort/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/semver-compare-sort/logic/`
- 测试文件夹：`devtools-web/src/tools/semver-compare-sort/__tests__/`
### API 信息
- 无后端 HTTP 调用；解析、比较、排序与范围判定均在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `semver-compare-sort` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中解析规则切片、比较与排序、范围算子、表格与导出、示例与行级错误、大体量策略与 URL 同步（若实现）均可逐条在页面上验收。
- 纯 JS 单测覆盖解析主干、先行版顺序、并列稳定排序、非法行、范围包含判定与长度守卫等逻辑导出函数。
