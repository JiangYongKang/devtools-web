### 任务目标
- 支持在浏览器内按可编辑模板将多条变更说明组装为发版草稿：内置多套模板（Keep a Changelog 风格、简单日期列表、Conventional Commits 聚合预览等，页内列出字段占位符如 `{{version}}` `{{date}}` `{{sections}}` `{{items}}`）；支持自定义模板文本、占位符自动补全提示、实时预览与「仅渲染不写入」模式。
- 支持条目级丰富选项：条目类型（`feat`/`fix`/`BREAKING` 等标签可选集）、Scope 输入、关联 issue 号链接模板、中英文双语列、自动编号与重新编号、拖拽排序、批量前缀插入；支持按类型分组输出与「扁平列表」输出切换；支持从粘贴的原始 commit 列表智能粗提取（规则在页内声明，失败时降级为整段放入未分类）。
- 支持日期与版本注入：`{{date}}` 支持 ISO/本地短日期/时间戳；`{{version}}` 支持 semver 校验与「从上一版本 bump」辅助按钮（major/minor/patch，仅字符串运算不调用外网）；支持「未填占位」策略（留空、写 `TBD`、标红错误）三选一且与 `errorCode` 一致。
- 提供示例一键填充、从剪贴板追加条目、清空与恢复默认模板、复制全文与下载 `CHANGELOG-draft.md`；支持模板变量「转义」语法（页内固定，如字面 `{{`）与多行字符串；对模板语法错误、循环引用占位、条目数与生成字节上界给出明确错误与恢复建议。
- 大体量条目使用虚拟列表或分帧渲染；可选将当前模板与条目序列序列化到 `localStorage` 草稿键（键名页内固定）；所有渲染为安全文本或受控富文本策略（禁止执行用户模板中的脚本）；Worker 可选用于大文本合并。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/changelog-draft-builder/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/changelog-draft-builder/logic/`
- 测试文件夹：`devtools-web/src/tools/changelog-draft-builder/__tests__/`
### API 信息
- 无后端 HTTP 调用；模板渲染与版本 bump 字符串运算均在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `changelog-draft-builder` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中多模板、占位符、条目 CRUD 与排序、分组与预览、日期版本、bump 辅助、导出与错误语义均可逐条验收。
- 纯 JS 单测覆盖模板渲染、缺占位策略、条目重排键稳定、非法模板与长度守卫等导出函数。
