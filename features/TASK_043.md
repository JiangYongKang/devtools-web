### 任务目标
- 支持多段 URL 与文件系统路径片段的安全拼接与规范化：模式切换（仅 URL / 仅 POSIX / 仅 Windows / 混合探测）、是否消解 `..`、是否折叠重复分隔符、是否保留尾部斜杠、是否强制绝对根；URL 侧支持 scheme 检测、query 与 hash 保留策略、默认端口剥离选项、百分号编码归一（大小写与 `+` 空格语义页内固定）。
- 安全策略丰富可配：拒绝含 `..` 穿越结果的输出并 `errorCode` 标明、拒绝 `javascript:` 等危险 scheme、可选允许 `file:` 片段但页内强警示；路径侧可选拒绝 Windows 保留设备名、高亮可疑盘符与 UNC 前缀；支持「仅诊断不输出」模式列出每步拼接的中间态与警告级别。
- 支持多行批量：每行一组片段（分隔符可配置为 `|` 或制表）、批量结果表与「仅显示第一处错误」开关；支持将输出一键转为「正斜杠统一」或「反斜杠统一」展示列；支持相对基路径 + 多个子路径的树形预览（只读字符串树）。
- 提供示例一键填充（含恶意穿越样例、双斜杠、URL 含中文片段、Windows UNC）、复制每条结果与复制诊断 JSON；支持用户保存「常用策略预设」到 `localStorage`（键名页内固定）与一键应用预设。
- 对片段条数、单段长度、合并总长与批量行数设页内上界；大体量批量使用分帧或 Worker；所有结果以纯文本或代码块展示防 XSS；空片段与全空白输入有独立 `errorCode`。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/safe-url-path-joiner/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/safe-url-path-joiner/logic/`
- 测试文件夹：`devtools-web/src/tools/safe-url-path-joiner/__tests__/`
### API 信息
- 无后端 HTTP 调用；拼接、规范化与安全判定均在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `safe-url-path-joiner` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中 URL/路径双域、选项矩阵、批量与诊断、示例与预设、上限与错误码均可逐条验收。
- 纯 JS 单测覆盖穿越拒绝、编码归一、UNC、危险 scheme、批量行解析与长度守卫等导出函数。
