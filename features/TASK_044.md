### 任务目标
- 支持 Unicode 域名与 Punycode（`xn--`）双向转换与校验：选项含大小写折叠、`xn--` 段大小写输出、是否显示 U-label 与 A-label 对照表、是否尝试 IDNA2008/UTS46 语义切片（页内声明与 `Intl`/`URL` 能力探测结果）；支持逐标签拆分展示、非 ASCII 标签高亮与「混合脚本」警告（规则简化须在页内列出）。
- 支持批量多行：每行一个域名、独立错误列、导出 TSV；支持「仅校验不转换」与「仅 punycode 解码」快捷开关；支持粘贴带 `http://` 前缀时自动剥离主机部分（可选开关）；对超长标签、非法 punycode、空标签与总长度上界返回行级 `errorCode`。
- 提供教学向辅助：展示每标签的码点序列（可选十六进制与 `U+` 格式）、Bidi 控制字符检测提示、不可见字符标红；一键复制 A-label、U-label 与诊断摘要；示例一键填充（中文域、混合域、错误 punycode）。
- 提供对比视图：原始输入与规范化输出并排、差异字符级高亮（纯 CSS/文本实现）；可选「与浏览器 `new URL` 行为对照」列（若不可比则灰显并说明）；支持将结果编码为可分享 URL 查询串（仅本工具状态，不请求外网）。
- 性能与边界：批量行数与单域名字节上界页内声明；节流解析；所有展示防 XSS；无 `Intl` 或相关 API 时的降级路径与页内引导。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/idn-punycode-converter/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/idn-punycode-converter/logic/`
- 测试文件夹：`devtools-web/src/tools/idn-punycode-converter/__tests__/`
### API 信息
- 无后端 HTTP 调用；编解码与校验均在浏览器内完成，不发起 DNS 查询。
### 任务约束
- 当前任务只允许读取和修改 `idn-punycode-converter` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中双向转换、批量、校验、标签表、警告与示例、对照列与分享参数、降级路径均可逐条验收。
- 纯 JS 单测覆盖 punycode 往返、非法输入、前缀剥离、长度守卫与批量行解析等导出函数。
