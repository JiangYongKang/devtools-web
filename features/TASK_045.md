### 任务目标
- 支持扩展名与 MIME 类型双向查询：内置可版本化的对照表（页内声明数据来源为静态 JSON/TS 常量，可按「常见 Web / 办公 / 压缩 / 音视频」分面筛选）；支持带点或不带点扩展名输入、大小写折叠、MIME 带参数时剥离 `;charset=` 等选项、多候选 MIME 时排序键（优先级字段或字母序）页内固定。
- 支持批量与模糊：多行扩展名或 MIME 批量查询表、可选「前缀模糊」与「子串搜索」开关（性能上界页内声明）；反向查询时展示「同 MIME 多扩展」列表与「推荐扩展名」标记规则；支持用户本地「覆盖表」追加（存 `localStorage`，键名固定）与导入导出 JSON。
- 支持魔数辅助（纯前端）：用户上传文件头若干字节（大小上界）时尝试推断 MIME 并与扩展名交叉校验，输出「一致 / 冲突 / 未知」三态及说明；不上传完整文件至任何服务器，仅在内存读取 `File.slice`。
- 提供示例一键填充、复制查询结果 TSV、下载当前视图为 CSV；支持按分类折叠展示与「仅显示未命中」过滤；对未知键、空输入、表版本切换（若提供下拉）给出 `errorCode` 与建议。
- 大体量表搜索使用防抖与可选 Worker；所有表格单元为纯文本渲染防 XSS；可选深色模式下列表对比度说明（样式仍限本目录或复用全局 token 但不改其他任务目录）。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/extension-mime-lookup/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/extension-mime-lookup/logic/`
- 测试文件夹：`devtools-web/src/tools/extension-mime-lookup/__tests__/`
### API 信息
- 无后端 HTTP 调用；查表、模糊与本地覆盖均在浏览器内完成；魔数推断仅读本地 `File`。
### 任务约束
- 当前任务只允许读取和修改 `extension-mime-lookup` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中双向查询、批量、模糊、多候选、本地覆盖导入导出、魔数交叉校验、示例与导出均可逐条验收。
- 纯 JS 单测覆盖归一化、参数剥离、冲突判定、模糊匹配边界与 `localStorage` 序列化格式（对纯函数层可注入 `storage` 替身）。
