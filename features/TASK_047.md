### 任务目标
- 支持跨平台文件路径规范化与多视图展示：目标平台切换（POSIX / Windows / 中性展示）、分隔符可视化（高亮 `/` 与 `\`）、可选消解 `.` 与 `..`、折叠重复分隔符、统一盘符大小写、UNC 路径识别与高亮、相对/绝对根判定与「危险穿越」拒绝策略（与 `errorCode` 对齐）。
- 支持批量多行路径、每行独立诊断列（保留名命中、空段、尾随点规则）；支持「仅归一化分隔符不消解 `..`」与「严格 POSIX」快捷预设；支持将路径拆为 `root` / `segments[]` / `basename` / `ext` 结构化 JSON 视图（扩展名规则页内固定，含多点文件名选项）。
- 支持对比模式：原始与规范化并排、差异字符级标色；支持「正斜杠导出」「反斜杠导出」「URL file scheme 预览（file:///）」三按钮且说明 Windows 盘符编码差异；支持路径与多段拼接联动（若本工具内提供「子路径追加」区，须与 043 语义不冲突或明确为简化版仅本页使用）。
- 提供示例一键填充（UNC、混合分隔符、含空格、`..` 穿越、Windows 保留名）、复制结构化 JSON 与复制单行规范化结果；支持用户预设存 `localStorage`；大体量行数上界与分帧渲染说明。
- 所有处理为字符串级不访问真实文件系统；输出纯文本/JSON 字符串防 XSS；空输入与全空白独立提示。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/filepath-normalizer/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/filepath-normalizer/logic/`
- 测试文件夹：`devtools-web/src/tools/filepath-normalizer/__tests__/`
### API 信息
- 无后端 HTTP 调用；解析与规范化均在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `filepath-normalizer` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中平台切换、UNC、批量诊断、结构化拆分、对比与导出、示例与上限均可逐条验收。
- 纯 JS 单测覆盖 `..` 消解、保留名、扩展名拆分、分隔符折叠与长度守卫等导出函数。
