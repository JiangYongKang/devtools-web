### 任务目标
- 支持在浏览器内编辑与校验 REST Mock 响应规则草稿（纯 JSON 或 YAML 文本 + 结构化表单双模式同步）：规则字段含路径模式（前缀/正则/精确可选集）、HTTP 方法多选、状态码、响应头键值表、响应体（JSON 文本或原始字符串）、延迟 ms、可选概率触发、可选 CORS 头模板；支持规则优先级拖拽与冲突检测列表（重叠路径+方法维度的诊断 `errorCode`）。
- 支持「静态场景包」：内置若干示例场景（CRUD 成功、分页、401、429、500）一键合并到当前草稿；支持导入/导出整个草稿为 JSON 文件（下载 Blob）；支持从剪贴板粘贴 OpenAPI 片段做「弱提示字段预填」（解析失败时降级提示，不得静默成功声称已完整转换）。
- 支持与本机 mock 配合说明区：生成「可复制」的 `curl` 示例（指向用户自填的 `http://localhost:...` 占位符，不自动发起请求）与 nginx/JSON-server 风格片段说明；提供「规则摘要」只读卡片（路径数、方法覆盖、延迟上界统计）；支持按标签过滤规则与全文搜索。
- 支持 JSON Schema 风格轻量校验（页内声明子集）与响应体 `JSON.parse` 预检开关；支持变量占位符 `{{now}}` `{{uuid}}` 在预览中的展开说明（展开规则页内固定，不执行任意代码）；大体量规则列表虚拟滚动与防抖校验。
- 支持草稿自动保存到 `localStorage`（键名固定）与手动清除；支持 URL 编码的「分享草稿」查询参数（长度上界页内声明，超限拒绝并提示）；所有渲染防 XSS；无任何对外 HTTP 调用。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/rest-mock-rules-draft/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/rest-mock-rules-draft/logic/`
- 测试文件夹：`devtools-web/src/tools/rest-mock-rules-draft/__tests__/`
### API 信息
- 无后端 HTTP 调用；校验、冲突检测、导入导出与说明文案均在浏览器内完成；不内置启动 mock 服务。
### 任务约束
- 当前任务只允许读取和修改 `rest-mock-rules-draft` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中双模式编辑、字段校验、冲突检测、场景包、导入导出、静态 curl 说明、占位符预览、自动保存与分享参数均可逐条验收。
- 纯 JS 单测覆盖规则归一化、冲突检测、JSON 预检、导入解析失败分支与长度守卫等导出函数。
