### 任务目标
- 支持常用二进制倍数（KiB/MiB/GiB…）与十进制数据单位（KB/MB/GB…）、比特率（kbps/Mbps）、以及「字节 per 秒」等组合单位之间的换算：选项含 IEC 1024 底与 SI 1000 底切换、是否显示双标（如同时显示 `GB` 与 `GiB`）、小数位与舍入模式（银行家、向上、向下、四舍五入页内固定语义）、科学计数法阈值、千分位分隔符与区域格式预览（`Intl.NumberFormat` 可用性探测与降级）。
- 支持批量换算表：多行「数值+源单位」粘贴、每行独立错误列、部分成功导出 TSV；支持「带宽 × 时间 = 传输量」计算器（时间单位 h/min/s 可选，输出多列）；支持「存储成本」纯展示列（用户输入单价/GB，仅乘法，页内声明非财务建议）。
- 支持进制与比特字节切换：如 `Mbit` 与 `MiB` 关系说明面板、常见误解 FAQ 折叠区；支持从剪贴板识别带单位字符串（正则切片页内声明）与失败时 `errorCode`；支持一键复制换算公式说明文本（含代入数值）。
- 提供示例一键填充、单位收藏夹（`localStorage`）、最近换算历史环形缓冲（条数上界）；大体量批量使用分帧；支持 URL 查询参数恢复当前选项；所有展示为纯文本防 XSS。
- 对溢出、非有限数、负数（若不允许则拒绝）、超大指数与批量行数设页内上界；可选 Web Worker 做批量高精度（若采用须在页内说明与 `BigInt` 使用边界）。
### 实现范围
- 页面文件夹：`devtools-web/src/tools/data-unit-converter/`
- 纯逻辑函数文件夹：`devtools-web/src/tools/data-unit-converter/logic/`
- 测试文件夹：`devtools-web/src/tools/data-unit-converter/__tests__/`
### API 信息
- 无后端 HTTP 调用；换算与解析均在浏览器内完成。
### 任务约束
- 当前任务只允许读取和修改 `data-unit-converter` 目录下文件，不可读取、不可修改其他任务工具目录。
### 验收标准
- 任务目标中 IEC/SI 切换、舍入与格式、批量与粘贴识别、带宽时间、示例与历史、溢出与错误码均可逐条验收。
- 纯 JS 单测覆盖单位归一、换算主公式、舍入边界、解析带单位字符串与批量聚合等导出函数。
