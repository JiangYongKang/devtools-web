### 任务目标
- 交付全站应用壳：顶栏（品牌、全局搜索、主题/偏好入口占位）、侧栏可折叠工具索引（按分类/标签/最近使用排序策略可配）、主内容区与移动端抽屉式导航；断点策略须覆盖窄屏/中屏/宽屏，键盘可达（Skip to content、焦点陷阱在抽屉打开时）、Landmark 与 `aria-*` 基本完备。
- 工具索引须与站点工具清单合并：支持从稳定数据出口只读加载元数据（`id`、`title`、`path`、`tags`、`status`）、客户端侧模糊过滤与拼音/首字母简拼（逻辑层实现，页内声明词典范围）、高亮匹配片段；大体量（百级以上）索引列表采用窗口化或分帧渲染并给出「已加载/总数」可访问文案。
- 提供「演示/验收」页内示例：一键注入虚构工具列表子集（含重复 `id` 与缺字段项）以验证合并去重规则、`errorCode` 与降级展示；支持将当前侧栏折叠态、搜索关键字写入 URL 查询参数并可分享恢复（与任务 060 对齐时在 DOC 说明由本任务或 060 哪一侧为权威写入，避免双写冲突）。
- 未知路由与非法工具 `id` 须独立空态/404 区，给出返回首页与「相近 `id` 建议」列表（基于编辑距离或前缀，逻辑纯函数）；全局加载条或骨架与路由切换的协调策略须在页面层可演示。
- 健壮性：清单加载失败、部分条目 JSON Schema 校验失败时的剔除与可展开「被忽略条目」诊断表；`prefers-reduced-motion` 下关闭抽屉过渡动画；禁止在壳层持久化用户敏感内容（若示例含令牌须仅会话级）。

### API 信息
- 无强制后端；若未来从 CDN 拉取清单，TASK 仅约定 `GET` JSON 数组形态、`ETag` 可选与超时/空体错误码映射，具体 Host 由环境变量注入，本任务目录内提供解析与校验纯函数及演示用的内存替身。
### 任务约束
- 当前任务只允许读取和修改 `devtools-web/src/platform/app-shell/` 目录内文件；不得修改 `devtools-web/src/tools/**` 下任一既有工具实现目录；只读消费全站清单时仅允许引用 `devtools-web/src/data/tools.js`（或仓库统一导出的 `src/data` 索引文件），不得向其中写入本任务状态。
### 验收标准
- 任务目标五条均可逐条在页面与逻辑层核对：响应式壳、索引合并与过滤、示例与 URL 状态、404 与建议、失败与无障碍降级。
- 纯 JS 单测覆盖清单归一与去重、模糊评分、编辑距离建议、折叠态序列化（若有）等导出函数；不依赖真实路由器的集成行为以 DOC 手工步骤为准。
