### 任务目标
- 抽象「工具工作台」布局：可插槽分区（输入、输出、操作条、元信息/说明、可选侧栏日志）；支持主从双栏与上下堆叠两种拓扑切换且记住于 `sessionStorage`（键名与版本前缀在逻辑常量中集中定义）；各分区支持 `min-height`、可拖拽调整高度（桌面端，指针事件降级为固定比例于触屏）。
- 操作区须统一编排：主操作、危险操作二次确认、禁用态与原因 `errorCode` 文案；输入/输出区支持「一键清空」「互换（若业务允许）」「复制全部」「下载为文件」委托回调（具体剪贴板与下载实现可依赖任务 055/056 的适配层接口形状，在本任务以 TypeScript 类型或 JSDoc 契约声明，不得复制实现）。
- 提供示例与说明位：内置「加载官方示例」按钮组（至少三组不同体积：小/中/大文本）与「注入校验错误示例」；说明位支持 Markdown 子集或纯文本（防 XSS 策略页内声明）；大文本输入采用防抖提交与字节数/行数实时统计（统计逻辑放逻辑目录）。
- 输出区须支持流式追加模式的虚拟滚动占位（逻辑层导出「分块合并与游标」纯函数）、JSON/纯文本展示切换、只读树折叠状态独立缓存；空态、加载态、错误态与只读态的插槽文案可配置。
- 边界：当输出超过页内配置字节阈值时自动降级为「仅提供下载句柄」提示；操作条在窄屏自动折行且主要按钮不被挤出视口（逻辑层提供断点辅助计算类名表）；所有对外 props 默认值须在逻辑层单测冻结，防止回归。
### 实现范围
- 页面文件夹：`devtools-web/src/platform/tool-workbench/`
- 纯逻辑函数文件夹：`devtools-web/src/platform/tool-workbench/logic/`
- 测试文件夹：`devtools-web/src/platform/tool-workbench/__tests__/`
### API 信息
- 无 HTTP；与剪贴板/下载/通知的集成仅通过回调注入，便于宿主应用替换。
### 任务约束
- 当前任务只允许读取和修改 `devtools-web/src/platform/tool-workbench/` 目录内文件；不得修改其他任务工具目录；不得在内联 JSX 中实现超过 30 行的复杂字符串处理或解析算法，须下沉至 `logic/`。
### 验收标准
- 五条任务目标均可对照演示页验收；示例按钮与错误注入路径可重复触发。
- 单测覆盖示例载荷生成、防抖间隔常量、输出分块合并、布局类名推导等纯函数；拖拽与虚拟列表若依赖浏览器 API，以可 mock 的适配器面单测。
