### 任务目标
- 建立设计令牌体系：颜色（背景/表面/边框/语义色阶）、间距、圆角、字体阶梯、阴影、动效时长与 `z-index` 阶梯均以 CSS 自定义属性集中导出；提供亮色、暗色两套令牌表及「跟随系统」三元模式，模式切换不得造成未样式化闪烁（须在 DOC 记录 `localStorage` 与 `matchMedia` 的读取顺序与内联 critical 片段策略）。
- 与仓库现有全局样式约定对齐：输出一份供构建链消费的 `:root`/`[data-theme]` 选择器映射表与一份供 JS 消费的结构化令牌对象（逻辑层导出），二者须由单测校验键集合一致；支持按域（shell / tool / code）前缀化令牌以避免工具页污染全局。
- 提供主题演示页：可视化色板与对比度检查（WCAG 相对亮度公式在逻辑层实现）、令牌搜索过滤、一键复制当前主题为 JSON 片段；含「示例」：载入虚构品牌主色并演算衍生色阶（HSL 调整算法页内说明局限，不得声称医疗级色觉无障碍）。
- 支持从 URL 查询参数临时覆盖主色与圆角（仅会话或一次性，刷新后恢复策略页内写明），并在非法颜色字符串时回退到默认令牌且给出 `errorCode`。
- 边界：`forced-colors` 高对比度模式下的降级（减少阴影、增强边框）；打印样式媒体查询下隐藏装饰阴影；禁止在令牌层引入第三方运行时 CDN 脚本。

### 任务约束
- 当前任务只允许读取和修改 `devtools-web/src/platform/theme-system/` 目录内文件；不得修改其他任务工具目录；全局 `index.html` 或根入口样式若必须调整，须在 DOC 列出精确 diff 并由评审确认，否则通过演示页内 `<style>` 注入仅限开发演示且生产禁用。
### 验收标准
- 任务目标五条均可演示与核对；亮色/暗色/系统三态与 URL 覆盖、非法色回退可复现。
- 单测覆盖对比度计算、令牌表键对称、HSL 衍生边界（饱和 0、明度 0/100）与 schema 校验。
