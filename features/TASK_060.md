### 任务目标
- 提供路由查询参数与工具 UI 状态的双向同步：逻辑层导出「序列化/反序列化」模式（含 `zod` 风格手写校验或等价纯函数），支持嵌套对象展平为点号键、数组重复键编码、布尔与枚举的字符串规范；非法参数剔除并生成人类可读 `warnings` 数组（不静默失败）。
- 分享链接：一键生成当前完整 URL（含 origin）、一键复制、对比「最小分享链接」（去掉默认值字段后的压缩算法在逻辑层实现且须稳定排序）；支持 `replace` 与 `push` 两种历史写入策略切换以避免污染后退栈（页内说明差异）。
- 演示页与示例：预置三组查询串（合法、部分非法、恶意超长）与一键加载；展示同步延迟（防抖毫秒可配）与并发编辑冲突解决策略（最后一次写入胜出 + 版本计数器）；与任务 051 协作时侧栏状态字段名须在 DOC 列冲突矩阵。
- 深层链接恢复：冷启动从 URL 恢复后触发 `onHydrated` 回调（由页面注入），并检测「恢复后校验失败」时分支到空态而非崩溃；支持 `sessionStorage` 备份最近一次成功状态以便用户撤销错误分享链。
- 边界：查询串总长度超浏览器常见上界时的截断策略与提示；`+` 与 `%20` 空格语义；UTF-8 非法百分号序列；在 SSR 与静态导出场景下无 `history` API 的降级（仅解析不入写）。
### 实现范围
- 页面文件夹：`devtools-web/src/platform/route-sync/`
- 纯逻辑函数文件夹：`devtools-web/src/platform/route-sync/logic/`
- 测试文件夹：`devtools-web/src/platform/route-sync/__tests__/`
### API 信息
- 无 HTTP；与路由器耦合处通过可注入的 `location`/`navigate` 接口抽象，单测使用内存替身。
### 任务约束
- 当前任务只允许读取和修改 `devtools-web/src/platform/route-sync/` 目录内文件；不得修改其他任务工具目录；不得假设特定路由器实现（React Router / TanStack Router 等）的内部 API，仅依赖最小表面。
### 验收标准
- 任务目标五条均可通过演示页与单测验证；压缩链接稳定性通过快照测试固定。
- 单测覆盖编解码往返、非法参数剥离、超长截断、防抖合并、`replace`/`push` 计数。
