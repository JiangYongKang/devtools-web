### 任务目标
- 工具页元信息中心：在 `localStorage`（键名带版本前缀）持久化「最近使用工具 slug 列表（含时间戳与访问次数）」「收藏夹集合」「用户自定义标签（多对多映射 slug）」；实现 schema 迁移函数（v1→v2 字段重命名与去重策略）与损坏 JSON 自愈（降级为空集合并提示备份导出）。
- 查询与展示：提供按标签交集/并集过滤、全文模糊匹配 slug 与标题别名表、排序（最近/最常/字母）；支持批量取消收藏与批量打标签；冲突解决：同 slug 多设备手工合并策略（「保留最新时间戳」或「并集标签」二选一全局设置）。
- 导入/导出：JSON 备份包含校验和字段（非加密哈希即可）与版本号；导入时校验 schema 与未知 slug 过滤策略（丢弃 vs 隔离到 `quarantine` 列表并展示）；示例按钮填充含冲突与损坏片段的样例以演示恢复路径。
- 纯逻辑层：`ToolUsageRepository` 类封装读写、节流写入（避免每次路由抖动打盘）、事件订阅接口（供 078 总线消费时仅在类型层声明，不引用 078 目录代码）；所有公共方法中文注释。
- 边界：存储配额溢出时 LRU 裁剪最近使用列表并 toast 提示；隐私模式 `localStorage` 抛错降级为内存态且页面顶部常驻警告；敏感 slug（匹配任务 070 定义之敏感键名模式）拒绝记录明文令牌样例；无障碍：列表虚拟化或分页二选一须键盘可操作。
